Android over Wi-FiWi-Fi ile Android

Two downloads, once. Then your phone shows up in games as a controller they already understand — and up to four phones can play on one computer. İki indirme, bir kereye mahsus. Sonrası: telefonun oyunlarda zaten tanıdıkları bir kumanda olarak görünür — ve tek bilgisayarda aynı anda dört telefona kadar oynanır.

Only want Bluetooth? Then you can stop reading: nothing on this page is needed. Install V-Pad from Google Play, pair the phone in your computer's Bluetooth settings like any controller, and play. Sadece Bluetooth mu istiyorsun? O zaman okumayı burada bırakabilirsin: bu sayfadaki hiçbir şey gerekmez. V-Pad'i Google Play'den kur, telefonu bilgisayarının Bluetooth ayarlarından herhangi bir kumanda gibi eşle ve oyna.

  1. Get V-Pad on the phone Telefona V-Pad'i kur

    Free on Google Play. If you already have it, make sure it is up to date — the Wi-Fi connection lives in the newer versions. Google Play'de ücretsiz. Zaten varsa güncel olduğundan emin ol — Wi-Fi bağlantısı yeni sürümlerde.

  2. Install the ViGEmBus driver ViGEmBus sürücüsünü kur

    This is what lets a game believe a real controller is plugged in. Over Bluetooth, Windows already has the driver it needs built in; over Wi-Fi your presses arrive as network traffic, so something has to present a controller to Windows — that is the only thing this driver does. It is made and signed by its own author, so Windows will not complain. Download it, double-click, answer Yes, then Next → Install → Finish. You only ever do this once: ViGEmBus is built to sit in the background — install it and leave it. You never run it, never install it again and never update it. Oyunun gerçek bir kumanda takılı sanmasını sağlayan şey bu. Bluetooth'ta Windows'un ihtiyaç duyduğu sürücü zaten içinde geliyor; Wi-Fi'da ise bastığın tuşlar ağ trafiği olarak ulaşır, yani Windows'a bir kumanda sunacak bir şey gerekir — bu sürücünün yaptığı tek şey o. Kendi yazarı tarafından üretilip imzalanmıştır, Windows itiraz etmez. İndir, çift tıkla, Evet de, sonra Next → Install → Finish. Bunu ömründe bir kez yaparsın: ViGEmBus arka planda kullanılmak için tasarlandı — kur ve bırak. Çalıştırman gerekmez; bir daha kurman ya da güncellemen de gerekmez.

  3. Run V-Pad Helper and leave it open V-Pad Helper'ı çalıştır ve açık bırak

    Double-click vpad-host.exe. Windows shows a blue warning the first time because the file is not signed yet — choose More info, then Run anyway. No black console window appears; instead you get a window with a QR code and a 6-digit number. Leave it open, your phone needs it in a moment. A small V-Pad icon also appears by the clock, bottom-right — that is the helper, and it keeps running after you close the window. It has to stay running while you play. vpad-host.exe'ye çift tıkla. Dosya henüz imzalı olmadığı için Windows ilk seferde mavi bir uyarı gösterir — Ek bilgi, sonra Yine de çalıştır. Siyah bir komut penceresi açılmaz; onun yerine QR kod ve 6 haneli sayı taşıyan bir pencere gelir. Kapatma, birazdan telefon isteyecek. Sağ altta, saatin yanında küçük bir V-Pad simgesi de belirir — yardımcı odur ve pencereyi kapatsan da çalışmaya devam eder. Oynarken çalışır durumda kalması gerekiyor.

    vpad-host.exe vpad-host.exe

    Current build 1.0.2 (bd99028), 2 September 2026. New version out? Download the current vpad-host.exe and run it — Start with Windows follows the copy you ran last. ViGEmBus stays the same; only vpad-host.exe ever gets updated. Güncel sürüm 1.0.2 (bd99028), 2 Eylül 2026. Yeni sürüm mü çıktı? Güncel vpad-host.exe'yi indirip çalıştır — Windows ile başlat en son çalıştırdığın kopyayı izler. ViGEmBus hep aynı kalır; yalnızca vpad-host.exe güncellenir.

  4. Point the phone at it Telefonu ona yönelt

    Phone and computer on the same Wi-Fi. Open V-Pad, choose Wi-Fi, and either scan that QR code or type the six digits. If Windows is blocking the way in, the helper says so and offers a one-click fix from its notification-area icon — bottom-right, behind the ^ arrow. After the first time your computer remembers the phone, so there is no code to type again. Telefon ve bilgisayar aynı Wi-Fi'de olsun. V-Pad'i aç, Wi-Fi'yi seç ve ya QR kodu tara ya da altı haneyi yaz. Windows yolu kapatıyorsa yardımcı bunu söyler ve bildirim alanındaki simgesinden tek tıkla açmayı önerir — sağ altta, ^ okunun arkasında. İlk seferden sonra bilgisayarın telefonu hatırlar, bir daha kod yazmana gerek kalmaz.

Four phones, one computer. Each phone needs its own code: open the helper's window again — New code — for the next player. Players are seated in the order they connect, and a phone that drops and comes back gets its old player number. Dört telefon, tek bilgisayar. Her telefon kendi kodunu ister: sonraki oyuncu için yardımcının penceresini yeniden aç — New code. Oyuncular bağlanma sırasına göre yerleşir; düşüp geri dönen telefon eski oyuncu numarasını geri alır.

Nothing happens in the game? Almost always the driver: if ViGEmBus is missing or was removed, V-Pad Helper says so in a message when it starts. Install it, then start the helper again. Oyunda hiçbir şey olmuyor mu? Neredeyse her zaman sürücü: ViGEmBus yoksa ya da kaldırıldıysa V-Pad Helper açılırken bunu bir mesajla söyler. Kur, sonra yardımcıyı yeniden başlat.
