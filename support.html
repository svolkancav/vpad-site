Report a problemSorun bildir

Please include: your phone model and OS version, whether the computer is Windows or macOS, and — if the helper is involved — the log file (its tray menu has Open log folder). The log says exactly which step failed and saves a lot of back and forth. Lütfen şunları ekle: telefon modeli ve işletim sistemi sürümü, bilgisayar Windows mı macOS mu, ve yardımcı program konuysa log dosyası (tepsi menüsünde Open log folder var). Log hangi adımda takıldığını tam olarak yazıyor ve karşılıklı yazışmadan çok zaman kazandırıyor.

TroubleshootingSorun giderme

The phone doesn't find my computerTelefon bilgisayarımı bulamıyor

Both must be on the same Wi-Fi network. The single most common cause is a VPN running on the computer: it hands out an address on a different network than the phone's. The helper's tray menu lists the addresses it published — the phone must be on one of those. Guest and corporate networks often block the discovery protocol (mDNS) entirely; a normal home network does not. İkisi de aynı Wi-Fi ağında olmalı. En sık sebep bilgisayarda açık olan bir VPN: telefondan farklı bir ağda adres veriyor. Yardımcı programın tepsi menüsü yayınladığı adresleri gösteriyor — telefonun o adreslerden birinin ağında olması lazım. Misafir ve kurumsal ağlar keşif protokolünü (mDNS) tamamen engelliyor olabilir; normal bir ev ağı engellemez.

It's listed but connecting failsListede çıkıyor ama bağlanmıyor

The Windows firewall prompt was most likely declined. Open Windows Defender Firewall → Allow an app through firewall and tick V-Pad Helper for private networks. Then quit and reopen the helper. Büyük olasılıkla Windows güvenlik duvarı istemi reddedilmiş. Windows Defender Güvenlik Duvarı → Uygulamaya izin ver bölümünden V-Pad Helper'ı özel ağlar için işaretle. Sonra yardımcıyı kapat ve yeniden aç.

Connected, but the game sees no controllerBağlandı ama oyun kumandayı görmüyor

Windows: the gamepad driver (ViGEmBus) is missing. The helper offers it on first run; you can also install it any time from the tray menu, and it says so plainly when it is absent. After installing, check Win+R → joy.cpl: an "Xbox 360 Controller for Windows" should be listed. If the driver was just installed, quit and reopen the helper. In Steam, also enable Settings → Controller → Generic Gamepad Configuration Support. Windows: gamepad sürücüsü (ViGEmBus) eksik. Yardımcı program ilk açılışta öneriyor; tepsi menüsünden de her zaman kurabilirsin ve eksikse bunu açıkça yazıyor. Kurduktan sonra Win+R → joy.cpl'e bak: listede "Xbox 360 Controller for Windows" görünmeli. Sürücüyü yeni kurduysan yardımcıyı kapat-aç. Steam'de ayrıca Ayarlar → Kontrolcü → Genel Gamepad Yapılandırma Desteği'ni aç.

macOS: grant Accessibility permission to the helper (System Settings → Privacy & Security → Accessibility), otherwise macOS accepts the input and silently discards it. Note that on macOS the pad is mapped to keyboard and mouse, not to a real controller — games that require a gamepad will not see one. macOS: yardımcıya Erişilebilirlik izni ver (Sistem Ayarları → Gizlilik ve Güvenlik → Erişilebilirlik), yoksa macOS girdiyi kabul edip sessizce çöpe atıyor. Ayrıca macOS'ta pad klavye ve fareye eşleniyor, gerçek bir kumandaya değil — kumanda zorunlu olan oyunlar bir kumanda görmez.

Windows says the file isn't safeWindows dosyanın güvenli olmadığını söylüyor

The helper is not code-signed yet, so SmartScreen shows "Windows protected your PC" for any new file it has not seen before. Choose More info → Run anyway. The source is public if you want to check it first. Yardımcı program henüz kod imzalı değil; SmartScreen daha önce görmediği her yeni dosya için "Windows bu PC'yi korudu" uyarısını gösteriyor. Daha fazla bilgi → Yine de çalıştır'ı seç. Önce incelemek istersen kaynağı herkese açık.

I ran the helper and no window openedYardımcıyı çalıştırdım, hiç pencere açılmadı

That is normal — it is a tray app, not a window. Look next to the clock; on Windows 11 new tray icons start out hidden behind the ^ arrow. A notification on first run confirms it started. Bu normal — pencereli bir uygulama değil, tepsi uygulaması. Saatin yanına bak; Windows 11'de yeni tepsi ikonları başlangıçta ^ okunun arkasında saklı olur. İlk açılışta çıkan bildirim başladığını doğruluyor.
